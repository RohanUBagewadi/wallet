info How Import Works

  • Type: If mapped, values like income, credit, cr → Income; expense, debit, dr → Expense. If not mapped, the sign of the amount is used (negative → expense, positive → income), or the Default Type is applied.
  • Category: Matched by name (partial matching supported, e.g. "food" matches "Food & Drinks"). If no match is found, it falls back to "Others" — creating it automatically if needed.
  • Wallet: Matched by name or currency. If no match, the Default Wallet is used.
  • Labels: Comma-separated values. Labels that don't exist will be created automatically.
  • Exchange Rate: Used to convert the amount to EUR. Defaults to 1.0 if not provided.
